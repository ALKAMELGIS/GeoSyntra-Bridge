ODA File Converter — inside GeoSyntra Bridge (no installation on the machine)

Windows: put ODAFileConverter_QT6_vc16_amd64dll.msi (free, opendesign.com → Guest Files → ODA File Converter)
in this folder and start GeoSyntra Bridge. It is unpacked here automatically (tools\oda\app) and used for every
DWG before LibreDWG. Nothing is installed in Program Files, no admin rights are needed.

Linux server: put ODAFileConverter_QT6_lnxX64_11dll.AppImage here (chmod +x). It runs without a display.
